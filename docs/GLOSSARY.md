# Глоссарий

**Analysis horizon** — максимальная часть звонка, доступная модели для конкретного кейса. CASE 1: 60 сек, CASE 2: 180 сек.

**CASE 1** — сценарий дополнительного сигнала риска внешнего психологического воздействия на клиента.

**CASE 2** — сценарий исследовательского/операционного речевого сигнала состояния сотрудника.

**Fail-closed** — поведение, при котором недоступность модели/контракта приводит к явной ошибке/недоступности, а не к подстановке фиктивного результата.

**Ground truth** — эталонная истинная метка. В экспертных разборах проекта человеческая оценка не объявляется абсолютной ground truth автоматически.

**Human-in-the-loop** — режим, при котором модельный сигнал интерпретируется человеком в контексте процесса.

**Model runtime** — отдельный локальный сервис, содержащий case-specific preprocessing и inference.

**Model ID** — идентификатор конкретной serving-версии модели/runtime.

**Quality layer** — отдельный набор полей, описывающих достаточность и качество материала для интерпретации score.

**Readiness** — технический статус готовности всех обязательных runtime-компонентов.

**Score** — численный модельный сигнал. Не обязательно является калиброванной вероятностью.

**Speech coverage** — фактический объём релевантной речи, попавшей в аналитическое окно.

**Supporting factors / XAI** — безопасное объяснение факторов, поддерживающих модельный результат.

**Runtime contract** — публичный формат взаимодействия integration API и закрытого/local model runtime.

**Mixed case** — экспертный случай, где разные компоненты оценки указывают в разные стороны и бинаризация неоднозначна.

**Domain shift** — изменение распределения данных относительно условий, на которых модель проверялась/обучалась.

**ASR** — automatic speech recognition, автоматическое распознавание речи.

**Speaker/channel attribution** — определение, какая сторона разговора произнесла конкретный фрагмент.

**Provenance** — информация о происхождении результата: версия модели, preprocessing, окно, fallback/quality status и другие безопасные технические сведения.

**Public integration layer** — код этого репозитория: API, маршрутизация, contracts, Docker, tests, документация.

**Private/proprietary runtime** — модельный или алгоритмический компонент, который может поставляться/запускаться отдельно и не обязан публиковать внутреннюю реализацию.

**Research-only** — экспериментальная конфигурация, не считающаяся финальным runtime без отдельного freeze/validation.

**Serving artifact** — файл модели/скейлера/энкодера/конфигурации, необходимый для inference.

**Control / expert review** — фиксированная подвыборка, используемая для дополнительной рецензии поведения модели, а не для незаметной постфактум подгонки порога.
