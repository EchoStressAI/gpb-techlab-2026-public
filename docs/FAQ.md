# FAQ

## Почему model weights не лежат в public repo?

Публичный repository отвечает за integration contract. Model artifacts могут иметь отдельные лицензионные, IP и data-governance ограничения и подключаются через локальный runtime.

## Значит ли это, что проект не работает без закрытой модели?

Integration API запускается и тестируется самостоятельно, но реальный ML inference требует подключённого case runtime. Если runtime отсутствует, API честно возвращает `MODEL_RUNTIME_UNAVAILABLE`.

## Почему не положить fake model для красивого demo?

Потому что фиктивный score создаёт ложное ощущение работоспособности. Fail-closed поведение — часть архитектуры.

## Почему CASE 1 и CASE 2 не объединены в один scorer?

Это разные задачи с разными ролями, временными окнами и интерпретацией результата. Общим является integration layer, а model runtime разделены.

## Почему CASE 1 только 60 секунд?

Задача требует раннего сигнала. Фиксированное окно также защищает от использования информации, которая появилась позже разговора.

## Почему CASE 2 только 180 секунд?

Это рабочий контракт кейса. Важно, что фактическое количество операторской речи внутри 180 секунд может быть меньше самого окна.

## Если эксперт и модель не согласны, кто прав?

Однозначного ответа без независимой ground truth может не быть. Экспертный разбор используется для анализа конструкта и причин расхождений, а не для автоматического объявления одной стороны ошибочной.

## Почему нельзя назвать высокий CASE 2 score «выгоранием»?

Потому что речевой сигнал может отражать ситуативное напряжение, раздражение, индивидуальную манеру речи или другие факторы. Корректнее говорить о модельном state signal и его ограничениях.

## Можно ли использовать CASE 2 для автоматического кадрового решения?

Нет. Публичная модельная карта прямо запрещает такое использование. Система не предназначена для автоматического кадрового, дисциплинарного, медицинского или страхового решения о человеке.

## Чем `/health` отличается от `/readiness`?

`/health` показывает, что integration API жив.

`/readiness` показывает, доступны ли оба model runtime.

## Что произойдёт, если runtime вернёт неправильный horizon?

Integration layer отклонит ответ как `MODEL_RUNTIME_CONTRACT_ERROR`.

## Как обновлять модель без изменения frontend?

Сохранить публичный runtime contract и заменить versioned case runtime. Новая содержательная модель должна иметь новый `model_id`.

## Можно ли подключить runtime на другом языке/стеке?

Да. Публичный gateway требует HTTP contract, а не конкретную внутреннюю реализацию. Runtime может быть Python, C++/binary, отдельный container и т.д.

## Можно ли использовать внешний облачный API?

Технически HTTP contract это допускает, но для банковского on-prem сценария предпочтителен локальный runtime внутри защищённого контура.
