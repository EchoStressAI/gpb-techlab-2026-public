# Команда

## EchoStressAI

Решение GPB TechLab 2026 объединяет компетенции в Data Science, ML-инженерии, психофизиологии, backend/frontend разработке и enterprise-внедрении.

### Вероника Заславская — CEO / руководитель проекта

- кандидат технических наук;
- продуктовая и исследовательская координация;
- Data Science / ML;
- разработка методологии анализа речевых сигналов;
- постановка экспериментов и интерпретация результатов;
- координация интеграции CASE 1 / CASE 2.

В проекте отвечает за продукт, исследовательскую логику и согласование научного и технического контуров.

В проекте помогает отделять наблюдаемые речевые признаки от слишком сильных психологических трактовок и формулировать проверяемые научные гипотезы.


## Принцип работы команды

Для конкурсного решения разделены четыре контура:

1. **Research** — гипотезы, validation, error analysis.
2. **Frozen runtime** — только зафиксированная serving-логика.
3. **Integration** — API/UI/Docker/on-prem.
4. **Public submission** — проверяемая документация и безопасный открытый код без банковских данных и proprietary core.

Такое разделение помогает не смешивать исследовательский эксперимент с финальным демонстрационным результатом.
